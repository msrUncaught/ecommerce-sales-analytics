# 📊 E-Commerce Sales & Profit Analytics Case Study

## 📌 Project Overview
This project presents an end-to-end data analytics case study analyzing 1,000+ e-commerce transactions across product categories, monthly revenue trends, and regional sales performance in India. 

The project covers data cleaning, exploratory data analysis (EDA), SQL aggregation/window functions, and an interactive Excel dashboard with multi-connected slicers.

---

## 🛠️ Tools & Skills Used
* **Excel:** Data cleaning (`TRIM`, `PROPER`, date parsing), Pivot Tables, dynamic KPI scorecards, and interactive dashboarding using Slicers & Report Connections.
* **SQL:** Aggregate metrics, `GROUP BY`, `HAVING` filters, Common Table Expressions (CTEs), and Window Functions (`DENSE_RANK()`, `LAG()` for Month-over-Month growth).
* **Business Analytics:** Profit margin analysis, seasonality detection, and cross-selling strategy.

---

## 💡 Key Business Insights
1. **Core Revenue Engine:** **Laptops** drive the majority of business revenue (**₹39.84M**, representing 62.2% of total revenue) with a top category profit margin of **16.41%**.
2. **Seasonal Demand Peak:** **June** recorded peak annual performance reaching **₹7.01M in revenue** and **₹1.12M net profit**.
3. **High-Margin Accessories:** Low-volume categories like **Mice** achieve high profit margins (**16.05%**), presenting immediate checkout bundling/cross-selling opportunities.
